# JFG Clinic Landing

Landing page Next.js prête pour GitHub + Vercel.

Variables Vercel utiles :

- `NEXT_PUBLIC_LEAD_WEBHOOK_URL` : URL du webhook Make pour envoyer les leads.
- `NEXT_PUBLIC_META_PIXEL_ID` : Pixel Meta du compte publicitaire concerné.

Le formulaire envoie notamment : nom, téléphone, e-mail, âge, taille, poids, IMC, offre recommandée, attentes, zones, opt-in message, centre, UTM et date d'envoi.
